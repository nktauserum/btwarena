# btwarena 

Header-only библиотека, реализующая arena allocation с помощью битового массива. Расшифровка глупого названия: bitwise (operations) — arena (allocation).

### Принцип работы

Вся память выделяется в стеке и не требует ручного освобождения — главное не допускать выхода экземпляра Pool из области видимости при ещё использующейся памяти оттуда. 

Основную работу по контролю над выделяемой памятью выполняет битовый массив __bitmap__ в объекте Pool. Согласно захардкоженной постоянной POOL_CAPACITY = 16, ему требуется шестнадцать битов для корректной работы (uint16_t). POOL_CAPACITY означает максимальное количество объектов, которые могут быть размещены в памяти. Размер этих объектов определяется BUFFER_SIZE — не забудьте объявить в своей реализации (иначе ошибка).

При выделении нового блока памяти производится линейный поиск свободного бита по массиву. Если он найден - возвращаем соответствующий ему блок из __arena__ и делаем xor на этот бит, инвертируя его состояние. Если пока что свободной памяти нет, то увы, но вернётся NULL.

Освобождение памяти происходит обратным образом: на основе разницы в адресах переданного указателя и начала массива __arena__ вычисляется позиция отвественного бита в __bitmap__. Если адрес в памяти не находится в диапазоне арены, функция возвращается, будто ничего не случилось (лучше следите за происхождением её аргументов). Ответственный бит всегда ставится в 1, что косвенно страхует от ошибок, подобных double-free. 

Пока всё вроде просто.
